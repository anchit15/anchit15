## Featured

**[sentinel-detections](https://github.com/anchit15/sentinel-detections)**: 12 Microsoft Sentinel detections in KQL, mapped to MITRE ATT&CK and tested in CI against real attack recordings.
Every rule has to fire on its attack data and stay quiet on unrelated activity. On the five rules the data can measure, tuning cut false positives from **197 to 0**. The rules follow Sentinel's schema and export as an ARM template.

**[Hydra Aegis](https://github.com/Aagash-Official/hydra-aegis-aws)**: AI security platform ([hydraaegis.co.uk](https://hydraaegis.co.uk)). MSc team project, graded First.
I was technical lead for the **C2 detection engine**: a multi-stage pipeline on CTU-13 NetFlow data. It combines a flow-level Random Forest (F1 = 0.91), host-level beaconing detection and a recurrence-pattern detector, catching **16/16 infected hosts** with leak-free evaluation and confidence-scored host assessments.
